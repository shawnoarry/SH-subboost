# AI 独立分流版

在快速配置的「选择模板」或模板库的「内置」页选择 **AI 独立分流版**。该模板基于完整版，其他分类保持一致，原有精简版、标准版、完整版继续可用。

生成的新配置包含四个手动选择组：

| 分组 | 覆盖范围 |
| --- | --- |
| 🤖 OpenAI / Codex | OpenAI 规则集中的 ChatGPT、API 和 Codex 相关域名 |
| 🧠 Claude | Anthropic / Claude 相关域名 |
| ✨ Gemini | Google Gemini 规则集中的 AI 网页和 API 域名 |
| 🤖 其他 AI | 综合 AI 规则集中的其他服务 |

供应商规则优先于综合 AI、Google 和 Cloudflare IP 规则；YouTube、普通 Google、GitHub 仍有独立分组。规则集沿用项目现有的 MetaCubeX 远程 MRS 来源，不包含个人节点、订阅链接或固定节点选择。

在 SubBoost 中选择模板后，检查生成预览，再保存为一个新订阅。导入 Clash Verge 后，在「规则」模式的代理页面分别给三个 AI 分组选择节点；YouTube 和普通网页可选择低倍率线路。默认各服务组跟随「节点选择」，未手动选择时不会自动识别家宽或低倍率节点。切换内置模板会重置规则编辑，请先保存需要保留的自定义规则。

关闭一个类目会省略它的规则，流量继续匹配后面的规则，最后由「漏网之鱼」处理；关闭类目不代表自动直连。例如关闭 Gemini 类目后，相关流量仍可能匹配综合 AI 或 Google 规则。

同一个登录、验证码或 CDN 域名可能被多项服务共享，因此这是按规则集内域名进行分流，不保证每个服务的所有关联请求完全隔离。若某个具体请求走错分组，可根据 Clash 的连接记录补充更精确的域名规则，放在宽泛规则之前。

订阅更新仍会使用保存在该订阅中的模板和分组设置。两台 PC 使用加密工作配置传递编辑设置时，请都更新到包含此模板的 SubBoost 版本。
